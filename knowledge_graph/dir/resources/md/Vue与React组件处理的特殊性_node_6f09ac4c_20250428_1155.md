# Vue与React组件处理的特殊性

## React组件特性及处理 (antd-renderer)

1. **JSX语法处理**:
   - React组件使用JSX语法，需要通过Babel转换
   - 转换过程需要引入相应的预设和插件
   ```javascript
   const transformedCode = transform(code, {
     filename,
     presets: ["react", "env", "typescript"],
     plugins: ["transform-modules-commonjs"],
   }).code
   ```

2. **组件结构特点**:
   - React组件是函数或类，可以直接导入使用
   - 通常使用 `export default` 导出组件
   - 组件逻辑、JSX结构和样式可分布在不同文件中

3. **热替换与动态导入**:
   - 支持组件的热替换和动态导入
   - 在构建和开发环境中有不同的处理方式

4. **错误边界处理**:
   - 使用 ErrorBoundary 组件捕获渲染错误
   - 支持组件级别的错误隔离和恢复
   ```javascript
   <ErrorBoundary>
     <Component {...props} />
   </ErrorBoundary>
   ```

## Vue组件特性及处理 (aries-ui-renderer)

1. **单文件组件格式**:
   - Vue通常使用单文件组件格式(.vue)
   - 需要处理 `<template>`, `<script>`, `<style>` 标签
   ```javascript
   const templateMatch = componentString.match(/<template>([\s\S]*)<\/template>/)
   const scriptMatch = componentString.match(/<script>([\s\S]*)<\/script>/)
   const styleMatch = componentString.match(/<style scoped>([\s\S]*)<\/style>/)
   ```

2. **组合式API与选项式API**:
   - Vue 3引入了Composition API
   - 需要处理 `<script setup>` 语法
   - 支持两种不同的API风格

3. **样式隔离处理**:
   - Vue组件样式可以有scoped属性，需要特殊处理
   - 样式可以使用预处理器（less, scss等）
   ```javascript
   if (style) {
     const styleElement = document.createElement("style")
     styleElement.textContent = style
     document.head.appendChild(styleElement)
   }
   ```

4. **组件注册与引用**:
   - Vue组件需要注册后才能使用
   - 全局组件和局部组件有不同的处理方式
   ```javascript
   app.component('ComponentName', Component)
   ```

## 关键差异与适配挑战

| 特性 | React (antd-renderer) | Vue (aries-ui-renderer) | 适配挑战 |
|------|---------------------|------------------------|---------|
| 文件格式 | 多文件，主要是.tsx文件 | 单文件组件(.vue) | 需要处理两种不同的文件格式 |
| 组件定义 | 函数或类 | 对象或setup函数 | 不同的组件定义方式需要不同处理 |
| 模板语法 | JSX | Vue模板语法 | 两种不同的模板系统 |
| 样式处理 | CSS-in-JS或外部CSS | 内联style标签，支持scoped | 样式隔离和应用方式不同 |
| 组件通信 | Props和Context | Props和Provide/Inject | 组件间通信机制不同 |

## 适配策略建议

1. **保留各自的特性处理**:
   - 对于Vue组件，保留单文件组件的解析逻辑
   - 对于多文件导入，添加新的处理机制

2. **路径解析兼容**:
   - 引入与antd-renderer类似的路径解析逻辑
   - 但适配Vue的文件扩展名和导入规则

3. **错误处理增强**:
   - 为Vue实现类似ErrorBoundary的错误隔离机制
   - 增强错误信息的详细程度和定位能力

4. **模块缓存机制**:
   - 引入模块缓存，避免重复处理
   - 但需要适配Vue组件实例的创建方式
