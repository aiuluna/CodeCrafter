# aries-ui-vite-starter

> A starter kit for Element Plus with Vite

- Preview: <https://vite-starter.aries-ui.org>

This is an example of on-demand aries-ui with [unplugin-vue-components](https://github.com/antfu/unplugin-vue-components).

> If you want to import all, it may be so simple that no examples are needed. Just follow [quickstart | Docs](https://aries-ui.org/zh-CN/guide/quickstart.html) and import them.

If you just want an on-demand import example `manually`, you can check [unplugin-aries-ui/examples/vite](https://github.com/aries-ui/unplugin-aries-ui/tree/main/examples/vite).

## Project setup

```bash
npm install
```

### Compiles and hot-reloads for development

```bash
npm run dev
```

### Compiles and minifies for production

```bash
npm run build
```

## Usage

```bash
git clone https://github.com/aries-ui/aries-ui-vite-starter
cd aries-ui-vite-starter
npm i
npm run dev
```
